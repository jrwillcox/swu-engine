# Drop-in playmats

Put your own playmat scans/images here as `*.jpg` (or `*.png`) and reference the
filename from `src/playmats/playmats.ts` (the `file` field on a `Playmat`, or add
a new entry and map a leader name to it).

Official Star Wars / FFG–Asmodee playmat artwork is licensed IP — it is **not**
fetched, bundled, or redistributed by this project. The defaults shipped in
`playmats.ts` are original, trademark-free CSS backdrops. Anything you add here is
your own private asset.
