# Engine primitives log

Every effect, condition, observer and decision option added while encoding the card
pool, grouped by the encoding batch that built it.

Use it to find precedent: search for a card id (e.g. `SHD_142`) or a primitive name.
For the distilled reference, see [`../engine_seams.md`](../engine_seams.md).

## sor-set:13–15 — combat tricks

- **`excludes_event_targets`** predicate: reads the growing `event_ctx["excluded_target_ids"]` set (the plural of `excludes_event_target`) for "another … a third" chains. Attack Pattern Delta SOR_106.
- **`StatBonus.count="controller_resources"`**: scales a `SELF` `StatBonus` by resources controlled. 97th Legion SOR_118.
- **`Condition.ANY_BASE_DAMAGE_MIN`**: gates on either base's damage. Guerilla Attack Pod SOR_148.
- **`peek_top` mode `may_draw_or_discard_heal`**: a forced choice between drawing and discard-plus-heal N, via `push_peek_top(discard_heal=N)`. Reinforcement Walker SOR_119.

## sor-set:17 — miscellaneous abilities

## shd-set:01

- **`Condition.CONTROLLER_ATTACKED_OTHER_TRAIT_UNIT_THIS_PHASE(param=trait)`**: another friendly unit with the trait is in `game_memory.units_attacked_this_round`. Attacks happen only in the action phase and the set clears each round, so this round equals this phase (as with the `attacked_this_phase` predicate). Excluding the source lets one condition serve both Bo-Katan Kryze SHD_12 clauses.

## shd-set:02–04 — direct damage

- **`push_select_damage(decider_id=, after_resolve_idx=)`**: the `select_damage` decision can be decided by the bounty collector, as `push_select_token` allows. "Up to 1" is treated as mandatory. Val SHD_58, Wanted Insurgents SHD_167.
- **`DealDamageEqualTo` count `"source_damage"`**: the damage on the source. Krrsantan SHD_139.

## shd-set:03–05 — direct damage

- **`DealDamageEqualTo` count `"event_played_card_cost"`**: the opponent's just-played card's cost, recorded by the `WhenOpponentPlaysCard` matcher and passed to `_scaling_magnitude(event_ctx=)`; targets an enemy `ground_or_base`. Krayt Dragon SHD_172.
- **`Condition.SOURCE_ONCE_PER_ROUND_TRIGGER_AVAILABLE`**: once per round for any trigger. Its `CustomEffect` marks `f"{iid}:trig"` in `game_memory.activated_abilities_used_this_round`; the condition gates collection, so declining doesn't use it up. Toro Calican SHD_239.
- **Regroup token sweep**: `_enter_regroup` detaches attached tokens flagged `defeat_at_regroup` (like the unit sweep). A `WhenPlayed` gives a Shield via `attach_token` and sets the flag. Jetpack SHD_225.
- Reuse only: Ma Klounkee SHD_229 = In Pursuit TWI_221's "if you do" (`requires_prior_target`). Detention Block Rescue SHD_180 = Zeb LAW_45's conditional magnitude (6 if the target guards captives, via a `captured_by` scan). Vambrace Flamethrower SHD_177 = `GrantedAbility(OnAttack)` + `push_distribute_damage`.
- Flagged as escalations: IG-11 SHD_170's capture replacement, SHD_163 and SHD_226.

## shd-set:03 — framework session

- **`pay_and_steal_upgrade`** decision kind (`actions.push_pay_and_steal_upgrade`, `StealUpgrade`, `DeclineStealUpgrade`, `_stealable_upgrades`): pay a non-token upgrade's cost (`_exhaust_resources`) on another non-vehicle unit, then move it to the source with `_relocate_upgrade` if `_upgrade_target_spec`/`_spec_matches_ci` allow, else `_apply_defeat_unit` it. Control follows the host. Pre Vizsla SHD_142; a sibling of `move_upgrade` SHD_64.
- **Forced attack** (`game_memory.forced_attack = {player_id, unit_id}`, phase-scoped): while set and able, `actions._forced_attack_actions` makes `legal_actions` return only that unit's attacks (a unit if possible, else the base). Consumed by that player's next action in `actions.apply`; cleared at the phase change. Give In to Your Anger SHD_144.
- Both were registered in `_KNOWN_DECISION_KINDS`, `_decision_legal_actions`, the web prompts (`DECISION_PROMPTS`, now `_PROMPTS`) and the bot's `_SAFE_DEFAULT_ORDER`.

## shd-set:04 — framework session

- **`WhenPlayerDiscardsFromHand`** observer: "when a player discards a card from their hand". Any player (no owner check, like `WhenIndirectDamageDealtToUnit`), discards only. `actions.record_hand_discard(..., kind="discard")` feeds the `game_memory.hand_discards` ledger (disclose passes `kind="reveal"` and is excluded); `actions._fire_hand_discard_observers` drains it when the game settles. Uses `optional`, `DealDamage(unit_or_base)` and the `SOURCE_ONCE_PER_ROUND_TRIGGER_AVAILABLE` limiter (the `{instance_id}:trig` marker). Migs Mayfeld SHD_163.

Lando Calrissian JTL_3, Major Vonreg JTL_11. `push_select_token` also gained `arena=` and `exclude_ids=`.

## The ability-redo seam

- **`resolver._schedule_ability_redo`** ("use that ability again"), generalised from Aethersprite LOF_197's When Played version to When Defeated (Grand Admiral Thrawn JTL_2). One function, dispatching on trigger type; its three callers (inline resolve, mandatory-with-decision, `actions.AcceptTrigger`) call it unconditionally, no longer only for `WhenPlayed`. The redo is an ordinary `trigger_option` inserted just below the original, so it runs after the original and everything it spawned. No new decision kind.
- When Played spends `game_memory.when_played_redo_charges` when offered. When Defeated reads a `WhenDefeatedRedo` marker in play, charged only on accept (`redo_source_id`, `redo_cost_exhaust`, `redo_once_per_round` in the context); declining isn't a use. A redo is offered only while affordable, and `event_ctx["ability_redo"]` stops a redo arming another. Thrawn has one marker per side: undeployed exhausts him; deployed is free but once a round (`game_memory.when_defeated_redo_used_this_round`).
- **Bounty (`is_bounty=True`) and `WhenDefeatedAsUpgrade` don't count as When Defeated abilities:** a bounty is collected by the opponent (so `owner_id` would credit the wrong player), and the other is a defeat replacement.

## ash-set:01 — the Support keyword (the last engine keyword)

"When you play this unit or deploy this leader, you may attack with another unit. It gains this unit's other abilities for this attack."

- **The attack is reuse:** two bus listeners in `keyword_triggers.py` (`UnitEntersPlay`, as Ambush reads "when you play"; `LeaderDeployed` for the three ASH leaders) push `granted_attack` with `optional=True` and `exclude_source=True`, only when another unit could attack, checked with `_filter_granted_attacks`, the same function `legal_actions` uses. Support is registered before Ambush, so a unit with both resolves its own Ambush first (last in, first out).
- **The borrow is one modifier plus one read point.** `push_granted_attack(borrow_abilities=True)` makes `AttackWithUnit` put a `borrowed_abilities` `this_attack` modifier on the attacker, naming the lender; **`state.borrowed_ability_sources(state, ci)`** is the only reader, beside `ability_suppressed` (both the keyword layer and the resolver use it, and neither may import the other). Two consumers:
  1. `keywords.has_keyword`/`keyword_value` add the lender at the end of the guarded keyword-copy block (The Ghost JTL_53), so a borrowed keyword reads like a copied one, values included; `_KEYWORD_COPY_RESOLVING` guards recursion. Support itself is excluded ("other abilities"), so a borrowed attack can't chain another Support prompt.
  2. `resolver._collect_triggers` collects the lender's `TriggerAbility` specs with `source_ci` = borrower and `spec_ci` = lender (the `GrantedAbility` split, one card further), so the lender's On Attack resolves from the attacker.
  A leader lends whichever side is showing (`deployed_only`/`undeployed_only` read on the lender); a suppressed lender lends nothing. Everything lapses with the `this_attack` sweep.
- **Documented limitation: constant and activated abilities aren't borrowed.** Both are read by arena-keyed scans (`compute_power`'s constants, `legal_actions`' ability enumeration); only the keyword and trigger layers have a per-instance hook. So Scion Shuttle ASH_46's defender debuff stays with the printed card.

## twi-set:07 — framework addition: aura-granted Actions

- **`AuraGrantedAbility` wrapping an `ActivatedAbility`**, with **`UseAbility.actor_id`**: an aura giving an Action to every matching unit (the many-actor version of SHD_155's upgrade-granted Action). `source_id` names the spec, `actor_id` the unit using it. A new aura scan in `legal_actions` offers it once per matching unit the active player controls (skipped when no aura is in play). The source may be an enemy card, so the ownership check, `ExhaustSelf`/`DefeatSelf`, resolution and the once-a-round key all use the actor, and the aura's `target` is re-checked at apply time. `describe()` must name the actor (the web and replay layers tell same-kind actions apart by it). Satine Kryze TWI_47.
